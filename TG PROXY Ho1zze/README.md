# TG PROXY Ho1zze

**TG PROXY Ho1zze** — современный легковесный клиент WebSocket MTProto Proxy для Windows с интерфейсом в стиле iOS / Bento Cards.

Приложение запускает локальный прокси-сервер (по умолчанию `127.0.0.1:1443`), который перехватывает MTProto/SOCKS5 трафик Telegram Desktop и перенаправляет его через шифрованные WebSocket соединения (`wss://kws4.web.telegram.org/apiws`) напрямую в дата-центр Telegram **DC 4** (`149.154.167.220:443`).

Трафик маскируется под стандартное HTTPS/WebSocket веб-соединение, что позволяет эффективно обходить блокировки, замедление провайдеров (ТСПУ / DPI) и бесконечную загрузку медиафайлов (фото, видео, голосовые сообщения).

---

## 🚀 Особенности

* **Целевой IP строго DC 4 (`149.154.167.220`)**: Оптимизирован специально для европейского и российского кластера Telegram (DC4), решая проблему медленной загрузки контента.
* **WebSocket Tunneling**: Использует официальный веб-шлюз `wss://kws4.web.telegram.org/apiws`, который неотличим от обычного посещения веб-сайтов.
* **Поддержка MTProto и SOCKS5**: Автоматическое определение протокола клиента. Подключайтесь в 1 клик через `tg://proxy` или `tg://socks`.
* **Компактный черно-серый дизайн (Bento Grid)**:
  * **⚡ Главная**: Статус прокси (Запущен / Остановлен), кнопки быстрого подключения к Telegram и SOCKS5, адрес и секрет с кнопкой копирования, счетчики активных сессий, переданного и полученного трафика, таймер аптайма.
  * **⚙️ Настройки**: Настройка локального порта, DC IP (`4:149.154.167.220`), генерация случайного 32-значного hex-секрета, переключатель автозапуска с Windows, а также кнопка **«Сбросить настройки по умолчанию»**.
  * **📜 Логи**: Журнал событий в реальном времени с временными метками, автопрокруткой и кнопками копирования/очистки.
  * **Watermark**: Водный знак «Created by Hoizze».
* **Автозапуск с Windows**: При включении опции приложение автоматически прописывается в реестр автозагрузки Windows (`HKCU\...\Run`).
* **Работа в системном трее**: Сворачивание и управление через иконку в трее (открыть, запустить/остановить, выход).
* **Сверхлегкий вес**: Скомпилированный файл `TG PROXY Ho1zze.exe` работает нативно без установки Python, дополнительных сред и библиотек.

## 📥 Быстрый старт

1. Запустите файл **`TG PROXY Ho1zze.exe`**.
2. В главном окне нажмите **«▶ Запустить прокси»** (если он не запустился автоматически).
3. Нажмите кнопку **«🚀 Подключить»** (Telegram MTProto) или **«🛡️ Подключить»** (SOCKS5).
4. Telegram Desktop откроет окно подтверждения — нажмите **«Включить прокси»**.

## ⚙️ Настройки по умолчанию

| Параметр | Значение по умолчанию | Описание |
| :--- | :--- | :--- |
| **Порт** | `1443` | Локальный порт прослушивания |
| **DC IP** | `4:149.154.167.220` | IP дата-центра DC4 Telegram |
| **MTProto Secret** | `cf9106855e4be8121b426307cb2dd17b` | 32-символьный hex-секрет |
| **Автозапуск** | Выключен | Автозапуск при старте Windows |

В любой момент вы можете нажать **«🔄 Сбросить настройки по умолчанию»** на вкладке «Настройки», чтобы вернуть параметры к исходным.

## 🛠 Сборка из исходников

Если вы хотите пересобрать исполняемый файл:
1. Запустите файл **`build.bat`**.
2. Скрипт использует стандартный компилятор C# (`csc.exe`), встроенный в любую версию Windows, и мгновенно создаст `TG PROXY Ho1zze.exe`.
